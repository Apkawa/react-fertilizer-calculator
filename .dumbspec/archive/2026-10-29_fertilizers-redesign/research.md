## Deviation notes (Stage 4 Round B, 2026-10-29)

- **Import/export/reset of fertilizers**: mockup header keeps fertilizer controls on the
  fertilizer card; customer asked to move fertilizer import/export/reset into the
  «Импорт/Экспорт» card as a «Удобрения» row (parallel to «Рецепты»/«Настройки»). Header now
  holds plus + eye toggle only.
- **Eye toggle (hide inactive rows)**: not present in apps/web-design — added per customer
  request: open = all library rows, closed = checked rows only. Local `useState`, not
  persisted; hidden rows stay in DOM (`display:none`) so sortable indices stay aligned
  with the store.
- **Grip→checkbox→name spacing**: browser-measured 8px gaps via label margin-box trick
  (label width 2.5rem + `margin-right: -1.5rem`); hit target ≥40px preserved.
- **Plus icon**: re-drawn from mockup with stroke-2 (matching eye/import stroke); new
  `eye`/`eye-off` icons added to registry (18 icons) with PNG baselines.
- **Import semantics (legacy preserved)**: fertilizer CSV import merges parsed values into
  the current library by name/id — row order stays; it does not reorder the library.
