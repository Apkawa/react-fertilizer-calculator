# 2026-10-22_web-design: верстка текущего layout калькулятора гидропоники

**Created:** 2026-10-22T23:53:21+03:00

## Scope

Входящее (v2, после решения заказчика 2026-10-28):
- Статическая верстка **текущего layout** приложения — калькулятор (`/`): двухколоночная структура (FertilizerSelect слева, Recipe/Result/Options справа), боковое меню-табы, карточки импорта/экспорта, тюнер-модал и модалы результата — всё сохраняется визуально 1:1.
- Боковое меню обязательно: на desktop — видно; при уменьшении экрана/mobile — свёрнуто в гамбургер + drawer. Страницы (Удобрения/Формула/Плотность/Справка) **не реализуются** — только визуально понятно, как выглядит меню.
- Убирается **только** ForkMeOnGitHub-баннер.
- **Цветовая схема — из первой верстки `apps/web-design/style.css`** (заказчик: «она норм, реиспользовать можно»): токены light/dark, палитра элементов; 3 темы (system/light/dark).
- Файлы: `apps/web-design/index.html` + `apps/web-design/style.css` (Tailwind Play CDN), минимум JS.

Выходящее:
- Функциональность (расчёты, валидация, persistence) — нет; верстка с демо-данными.
- Реализация страниц Help/Formula/Density/FertilizerManager — нет.
- Концепция «3 шага» из первой версии — **отменена**, первая верстка structure discarded (палитра реиспользуется).

Анализ 2026-10-22 показал проблемы UX, но **заказчик решил** (2026-10-28): текущий layout в принципе весь нужен, ничего нельзя убрать; переосмысление отменено.

## Approach

1. **Верстка = визуальная копия текущего калькулятора** (`apps/web/src/components/Calculator/*`, `navigation/TabMenu.tsx`) на Tailwind Play CDN:
   - Sidebar с табами (Калькулятор, Удобрения, Парсер формул, Плотность, Справка + подменю) + ColorModeToggle; desktop ≥800px — visible; ниже — гамбургер + drawer overlay.
   - Двухколоночный layout (936px): left — `FertilizerSelect` (dropdown добавления + карточки выбранных с чипами элементов и граммовкой + удаление), right — `Recipe` (dropdown рецептов + save/tune icon buttons + 8 инпутов + чипы баланса + `tune`-модал), `Result` (сетка чипов 2×8 макро/микро с дельтами, чипы баланса, группы «Раствор A/B/C», итоги, «Сохранить комплекс»/«Отправить на миксер», модалы), `Options` (кнопка Calculate + карточки Раствор/Долив/Разбавление/Игнорировать/Точность), карточка Import/Export (icon-кнопки), footer с версией.
   - Mobile ≤800px: текущее поведение — stack в обратном порядке (result/options/recipe сверху, fertilizer select снизу).
2. **Палитра** — переиспользовать токены и компонентные классы из первой верстки (`style.css`): `--bg/--card/--text/--muted/--border/--primary/--danger/--ok/--deficit/--excess` + палитра элементов `--el-*`; переключатель темы 3 режима (system/light/dark) — как ColorModeToggle в sidebar (солнце/луна), системный режим через `prefers-color-scheme`.
3. **Демо-данные** те же: «Перец Минвата Базовый», 4 удобрения, результат Раствор A/B (8.2/69.7/99.3/17.5 г), всего солей 194.7 г, EC 1.83, 23 варианта · 0.006 с.
4. **Минимум JS**: тема, drawer-меню, generic открытие/закрытие модал.

## Constraints

- Язык интерфейса — русский.
- 16 элементов: 8 макро (NO3, NH4, P, K, Ca, Mg, S, Cl, г/л) + 8 микро (Fe, Mn, B, Zn, Cu, Mo, Co, Si, мг/л); результат сгруппирован по Растворам (A/B — макро/микро), итог: всего солей (г и г/л), EC.
- Палитра элементов: no3 зелёный, nh4 зелёный, p жёлтый, k оранжевый, ca серый, mg фиолетовый (значения из существующего `apps/web-design/style.css`).
- Content-колонка 936px; breakpoint 800px (`flex-col-reverse` на mobile).
- Tailwind Play CDN; `style.css` — токены, палитра элементов, компонентные классы.
- Иконки (menu, moon, sun, plus, close, save, tune, broom, import, export, restart, chevron-down) — inline SVG в верстке.
- Тема: `html[data-theme]`, 3 режима, localStorage; head-script без мигания темы.
