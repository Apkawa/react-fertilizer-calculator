# research: 2026-10-28_ui-redesign (internal notes, English)

## R1 — apps/web-design mockup: theme×scheme architecture

- Two orthogonal axes: theme mode `html[data-theme] = light|dark` (applied result; persisted key `theme`: light|dark|system, default system) and color scheme `html[data-scheme] = default|win95|retro|nature|science` (persisted key `scheme`, default `default`). Head script sets both attributes pre-paint; system mode listens to `matchMedia('(prefers-color-scheme: dark)')`.
- CSS load order: style.css → color-default.css → color-win95 → color-retro → color-nature → color-science. Specificity mechanism: light default `:root` (0-1-0); dark default `:root[data-theme="dark"]`; media fallback only in default scheme; scheme light = `html[data-scheme="x"]` (0-1-1) beats `:root`; scheme dark = `html[data-scheme="x"][data-theme="dark"]` (0-2-1) beats media fallback. 5 schemes × 3 modes = 15 combos; scheme dropdown = native `<select>` right of theme toggle button.
- Token governance: style.css defines NO tokens, only consumes `var(--*)`; all color literals live exclusively in color-*.css (guideline §4.4/§10). Core tokens (10), declared twice per scheme file (light+dark): `--bg --card --text --muted --border --primary --danger --ok --deficit --excess`. Element palette (9): `--el-no3 --el-nh4 --el-p --el-k --el-ca --el-mg --el-s --el-cl --el-micro`. Semantic layer: `.el-*` classes set only `--el-tint` (never paint text); consumers `.chip-el`/`.el-cell` use `color-mix(in srgb, var(--el-tint, var(--muted)) 12%/45%/30%, transparent)`.
- Scheme non-color overrides allowed: borders/radius/shadows/hover (win95: radius 0 + inset bevel; nature: radius .75rem + ok-shadow; science: crisp 1px + glow; retro: 2px borders, maroon-filled buttons). Scheme MUST NOT change typography/layout/spacing/motion (guideline §4.4).
- Tailwind mapping in mockup: colors bg/card/text/muted/border/primary/danger/ok/deficit/excess → var(--…); preflight off; breakpoints only arbitrary `min-[800px]`/`max-[1249px]`/`max-[800px]`, never `md:`.
