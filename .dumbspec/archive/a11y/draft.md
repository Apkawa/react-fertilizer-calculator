
Нам необходимо настроить доступность (это принесет пользу для использовании с playwright-cli)

1) добавить тесты доступности в e2e

```ts
import { test, expect } from '@playwright/test';
import { AxeBuilder } from '@axe-core/playwright';

test('интерфейс готов для ИИ-агента', async ({ page }) => {
  await page.goto('https://your-app.com');

  // Сканируем страницу на доступность
  const accessibilityScanResults = await new AxeBuilder({ page })
    .withTags(['wcag2a', 'wcag2aa']) // Стандарты доступности элементов
    .analyze();

  // Тест упадет, если у кнопок-иконок не будет aria-label
  expect(accessibilityScanResults.violations).toEqual([]); 
});

```

2) Пройтись по проекту и расставить aria-label там где это необходимо (и что там еще помимо этого?)


Хороший критерий приемки - это то что навигировать при помощи playwright-cli станет намного проще
