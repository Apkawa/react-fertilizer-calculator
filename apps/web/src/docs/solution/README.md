# Растворы и концентраты

## Основные понятия

**Монораствор** — раствор, содержащий одну соль и воду. Характеризуется:
- Концентрацией (г/л).
- Плотностью (г/мл).

**Концентрат** — смесь совместимых солей, не вступающих в реакции при хранении. Используется для упрощения приготовления рабочих растворов.
- Пример кратности: 100:1 означает, что 1 часть концентрата разводится в 100 частях воды.
- Обычно готовят два концентрата:
    - **А** — азотнокислые соли.
    - **Б** — сернофосфорные соли.

**Преимущества концентратов**:
- Удобство хранения (жидкая форма менее гигроскопична).
- Быстрое приготовление рабочего раствора.
- Безопасность (не требуется работа с сухими солями).

**Недостатки**:
- Ограниченная растворимость некоторых солей (например, сульфата калия).
- Риск кристаллизации при охлаждении.


## Монорастворы

### Приготовление монораствора:

(на примере 1.5 л раствора из 150 г соли)

1. Взвесьте пустую тару, обнулите весы.
2. Отмерьте 1.5 л воды по весу (1500 г).
3. Добавьте 150 г соли, растворите в горячей воде (до прозрачности).
4. Доведите объем до метки, взвесьте раствор.

### Концентрация

Вес сухой соли в граммах делим на объем в литрах 

> 150 грамм / 1.5 литров = 100 г/л.

Это значит что 1 литр раствора будет содержать в себе 100 грамм растворенного вещества, а 1 мл содержит 100 мг вещества. 

> Т.е. 100 г/л = 100 мг/мл = 0.1 г/мл

Значит для получения например эквивалента 5 грамм сухой соли таким раствором нам нужно: 

> 5 г = 5000 мг. 
> 5000 мг / 100 мг/мл = 50 мл

### Плотность

Сколько весит 1 миллилитр в граммах. 
Делим вес раствора в граммах на объем раствора в миллилитрах.

Например:

> 1800 гр. / 1500 мл. = 1.2 г/мл

Это значит, что мы можем отмерять жидкости по весу. 

Допустим нам нужно отмерить 50 мл.

Мы знаем, что 1 мл весит 1.2 г. Делаем расчет.

> 50 мл * 1.2 г/мл = 60 грамм.

Отмечаем на таре эти значения.


### Сколько растворять соли

1. Используйте таблицы растворимости (например, растворимость K₂SO₄ — 120 г/л при 20°C).
2. Учитывайте температуру хранения (при +5°C растворимость снижается на 20-30%).
3. Рассчитайте запас:  
   `Макс. концентрация = Растворимость × 0.8` (коэффициент безопасности).

    > **Пример**: Для K₂SO₄ макс. концентрация = 120 г/л × 0.8 = 96 г/л.

4. В случае если удобрение хорошо растворимо, то выбирайте количество соли исходя из удобства взятия объема. Взять 30-40мл проще чем 1-4мл. Так же с увеличением объема увеличивается точность.
