# ТЗ: статический макет «Калькулятор гидропоники» (визуальная копия текущего приложения)

> Предыдущая концепция «3 шага» заказчиком **отменена**. Новый макет — визуальная копия
> текущей раскладки приложения `apps/web` (сайдбар + две колонки калькулятора), палитра —
> из существующего `apps/web-design/style.css`.

## 1. Назначение

Разработать **статическую** вёрстку (без бэкенда, без вычислений, без роутинга) одностраничный
макет калькулятора гидропонных растворов: `index.html` + `style.css` в папке `apps/web-design/`.
Макет воспроизводит раскладку текущего приложения 1:1 (сайдбар с вкладками, две колонки
«Калькулятора», карточки, чипы, модалки). Все данные — **хардкод** из раздела «Демо-данные» (§6).
Единственная рабочая логика — минимальный JS: переключатель темы, drawer сайдбара, модалки,
переключение серости ряда удобрения чекбоксом (§3.1) и чекбоксы-аккордеоны карточек
«Долив раствора» / «Разбавление концентрата» (§3.4).

Документ самодостаточен: по нему вёрстальщик строит оба файла без обращения к исходникам
(единственное исключение — иконки: их SVG копируются из `packages/icons/src/icons/`, §7.6;
если недоступны — допустимы простые глифы-замены).

### 2.1. Сайдбар (десктоп, viewport ≥ 1250px)

- Панель слева, закреплённая: `position: fixed; inset-block: 0; left: 0; width: 300px;`
  фон `var(--card)`, правая граница `1px solid var(--border)`; контент сдвинут
  `padding-left: 300px` при ≥ 1250px (гамбург-кнопка скрыта при ≥ 1250px).
- Содержимое сверху вниз — список ссылок:
  **Калькулятор** (активная), **Удобрения**, **Парсер формул**, **Плотность**,
  **Справка** (заголовок submenu) + подпункты: «Как использовать», «Гайд для новичка»,
  «Профиль элементов» → «Примеры профилей», «Методика расчета», «Изготовление хелатов»,
  «Техника безопасности» → «Таблица опасности веществ», «Светокультура», «Виды установок»,
  «Ссылки и литература».
- Активная ссылка «Калькулятор»: `font-weight: 600; color: var(--primary)`.
  Остальные `var(--text)`, hover → `var(--primary)`. Ссылки инертны.
- Внизу сайдбара — переключатель темы (иконка-кнопка sun/moon/monitor, §5).

### 2.2. Сайдбар при < 1250px (drawer)

- Сайдбар скрыт при viewport < 1250px; в левом верхнем углу страницы — гамбург-кнопка
  (inline-SVG иконка `menu`), `aria-label="Открыть меню"`, `aria-controls="sidebar"`.
- Клик по гамбургу JS добавляет класс `drawer-open` на `<html>`:
  оверлей на весь экран (`background: color-mix(in srgb, var(--bg) 60%, transparent)`)
  + панель-drawer слева `width: 300px; height: 100vh; background: var(--card); box-shadow` —
  то же содержимое, что десктопный сайдбар, плюс внутри кнопка закрытия
  (иконка `close`, `aria-label="Закрыть меню"`, видна при < 1250px — `max-[1249px]:inline-flex`).
- Drawer: `role="dialog" aria-modal="true"`; при открытом `body { overflow: hidden }`.
  Закрытие: кнопка закрытия; дополнительно допустимо клик по оверлею и `Esc`.
- При ≥ 1250px гамбург скрыт, drawer недоступен (сайдбар всегда видим). При 800–1249px
  гамбург + drawer доступны, но раскладка остаётся **десктопной 2-колонной**: сетка
  калькулятора включается при ≥ 800px (§3/§4) и не зависит от сайдбара.

### 2.3. Footer

Одна строка в колонке контента, приглушённый мелкий текст, выровнен вправо:
`v1.0.0-demo` (в приложении формат `<версия>-<branch> <hash> [date]` — в макете упрощён до версии).

Две колонки без `<form>` (кнопки инертны):

### 3.1. «Удобрения» (левая колонка) — список-менеджер

Карточка секции. Концепция — **список-менеджер удобрений** вместо селектора:
селектор «Добавить удобрение» (`<select>`) **удалён** по требованию заказчика;
модалка редактирования удобрения **НЕ верстается**. Порядок рядов и данные — §6.

1. **Шапка секции** (ряд `flex items-center gap-2`): заголовок «Удобрения» жирным
   (`flex-1 min-w-0`), справа — четыре иконки-кнопки `.icon-btn` (иконки §7.6, инертны).
   **Первая — сразу после заголовка**: `plus` `aria-label="Добавить удобрение"`
   (т. заказчика: кнопка добавления вместо удалённого селектора), затем
   `import` `aria-label="Импорт удобрений"`, `export` `aria-label="Экспорт удобрений"`,
   `restart` `aria-label="Сбросить удобрения"` — в шапке карточки секции, top-right.
2. **Список рядов** (класс `.fertilizer-card`, `space-y-2`) — сначала 4 выбранных,
   затем 3 невыбранных демо-ряда. Каждый ряд:
   - **ручка-грип** в самом начале ряда: inline-SVG (6 точек сетки 24×24, `fill: currentColor`),
     `cursor: grab`, `aria-label="Переместить"`; drag-n-drop **не реализуется** (макет);
   - **чекбокс** непосредственно **слева от названия** (пожирнее, `aria-label="Выбрать «<имя>»"`);
   - название жирным (`flex-1 min-w-0`);
   - у **выбранных** рядов: масса (`text-sm font-semibold`) слева от правых кнопок; справа —
     две стандартные иконки-кнопки единого визуала `.icon-btn` (§5), порядок (т. заказчика,
     исправлено: edit **слева от del**, ранее была ошибочно «справа»): сначала **кнопка
     редактирования** `.icon-btn.edit-btn` — карандаш SVG (stroke-width 2, тот же стиль),
     `aria-label="Редактировать"`, затем `.icon-btn.del-btn` с trash-bin SVG
     (крышка+ручка+корпус, stroke как остальные), `aria-label="Удалить удобрение"` —
     **самая правая в ряду**; порядок шапки ряда: название → масса → edit → del; grip,
     чекбокс, название, масса, edit и del — на одной строке (высота массы
     `.fert-weight` синхронизирована с высотой иконки-кнопки);
   - у **невыбранных** рядов массы нет, но кнопки редактирования и удаления — те же, что
     у выбранных и в том же порядке (inactive-ряды тоже показывают edit/del, edit слева от
     del); ряд помечен
     классом `.is-inactive`:
     `opacity ~0.6`, название приглушённое (`--muted`), чипы — нейтральный серый tint
     через `color-mix(--muted)` (перебивает `.chip-el`), чекбокс снят;
   - JS (несколько строк): `change` чекбокса переключает `.is-inactive` у своего ряда
     (серость/opacity — в CSS); остальная логика не добавляется.
3. **Чипы состава** под шапкой ряда (`.chip .chip-el`) — оксидные имена как в приложении
   (NO3, NH4, P2O5, K2O, CaO, MgO, S) плюс **микро** (Fe, Mn, B, Zn, Cu, Mo, Co) — тон
   `--el-micro`, тот же, что в микро-ячейках результата (§3.3). Чип — 2 строки
   (`chip-label` сверху, `chip-value` снизу), квадрированная тонированная ячейка.
   **Суффикс «%» убран из значений чипов состава (т. заказчика): `chip-value` — только
   число** (например `17.149`); подпись «%NH4» balance-чипа остаётся — это подпись, не суффикс.
   **Balance-чипы — менее заметные (т. заказчика)**: базовый `.chip` **без границы**,
   подложка `color-mix(in srgb, var(--muted) 6%, transparent)` (было 12% + рамка);
   чипы элементов (`.chip-el`) сохраняют тон + рамку, но **плотнее** (т. заказчика):
   `padding ~0.45rem 0.4rem` (<800px ~`0.35rem 0.25rem`), `min-width ~2rem` — §5.
   Ряд чипов состава — **`flex flex-wrap gap-1`** (было `gap-1.5`): при 11+ чипов
   переносится на несколько строк (заказчик оценивает вместимость). Ряды balance-чипов
   Recipe/Result — как раньше, `flex flex-nowrap gap-2`, без переноса (§3.2, §3.3).
   Горизонтального переполнения страницы на 390px нет: перенос вместо переполнения
   (`scrollWidth == innerWidth`).
4. Левая колонка сохраняет классы порядка: `order-2 min-[800px]:order-1` (§3).

### 3.2. Recipe (правая колонка, сверху)

Карточка, содержимое:

1. Ряд: дропдаун рецепта `<select class="input">` (дефолт selected — «Перец Минвата Базовый»,

2. Иконки-кнопки рядом (заполненный primary): иконка `save` `aria-label="Сохранить рецепт"`;
   иконка `broom` `aria-label="Сбросить рецепт"`.
3. Ряд из 8 number-полей макроэлементов (г/л): подпись над полем + узкое поле (~3rem,
   текст по центру), `aria-label="Доза <элемент>"`:
   NO3 224 · NH4 14 · P 39 · K 264 · Ca 200 · Mg 36 · S 56 · Cl 0.
   Подписи — приглушённые (`--muted`, класс `.field-label`); `.el-*` текст не красят

4. Иконка-кнопка `tune` `aria-label="Настройки рецепта"` — открывает модалку «Тюнер рецепта» (§3.6).
5. Ряд balance-чипов (read-only; чип — квадратная тонированная ячейка, как в §3.1
   и как `.el-cell`: мелкая подпись сверху, значение под ней): ряд `flex flex-nowrap gap-2`,
   чипы `shrink-0` — **всегда одна строка без переноса**, в т.ч. на узких ширинах:
   ΔΣ I **−0.05**, EC **2.16**, %NH4 **6.3**, K:N **1.109**, K:Ca **1.32**, K:Mg **7.333**.

### 3.3. Result (правая колонка, середина)

Карточка, содержимое по центру:

1. Заголовок «Результат расчета».
2. Сетка элементов: **1 ряд × 8 макро ячеек** на всех ширинах — сетка `grid-cols-8` всегда,
   без переноса на несколько строк (класс `.el-cell` — **3 строки**: `.el-name` — имя,
   **жирное, `var(--text)`**; `.el-value` — значение г/л, **обычное (regular),
   `var(--text)`** — единый цвет имён/значений, т. заказчика §5; ниже `.el-delta` — дельта,
   мелкий, БЕЗ символа «Δ» (т. заказчика): только знаковое значение); подложка/рамка ячейки
   — тон элемента (`.el-*` задают `--el-tint`, текст больше
   не красятся); на мобильном (< 800px) ячейки компактнее — уменьшены padding
   и размер шрифта через `@media (max-width: 799px)` в `style.css` (§4):
   NO3 224/0 · NH4 14/0 · P 39/0 · K 313/−49 · Ca 165/+35 · Mg 0/+36 · S 56/0 · Cl 0/0.
   Окраска по знаку (т. заказчика): **положительное — зелёный «+» (`--ok`,
   `.status-pos`)**, **отрицательное — красный «−» (`--deficit`, `.status-neg`)**,
   **0 — нейтральный (`--muted`)**; прежние классы `status-ok/deficit/excess` убраны.
   В демо: K — «−49» красная, Ca и Mg — «+35»/«+36» зелёные, остальные — «0» нейтральные.
   Δ-подписи balance-чипов («ΔΣI») сохраняются без изменений.
3. Ниже — **1 ряд × 8 микро ячеек** (также `grid-cols-8` всегда), **3 строки — как
   макро** (т. заказчика): имя — жирное `var(--text)`, значение — обычное `var(--text)`

   чип S** (`--el-micro` = `--el-s`); суффикс «мг/л» **убран полностью**
   (единицы подразумеваются); третья строка — `.el-delta` с **`0`** (без «Δ»),
   нейтральный `--muted` — как «0» в макро-ячейках, без статус-класса:
   Fe 4500 · Mn 636 · B 636 · Zn 384 · Cu 69 · Mo 69 · Co 0 · Si 0 — все «0».

4. Ряд balance-чипов (как в Recipe — квадратные тонированные ячейки, как `.el-cell`):

5. Список дозировок: «Для 1 л раствора»; **Раствор A** — строки `8.2 г Нитрат аммония (NH4NO3)`,

   (пустая группа, как в приложении); «Всего солей: 194.7 г.»; «Концентрация солей: 194.7 г/л».
   На десктопе список занимает ~75% ширины карточки.
6. Статистика мелким текстом: «Обработано вариантов: 23 Время: 0.006 сек».
7. Две кнопки с иконкой и подписью — стандартный визуал `.btn` (§5): иконка `save` +
   «Сохранить комплекс» → модалка; иконка `broom` + «Отправить на миксер» → модалка (§3.6).

### 3.4. Options (правая колонка)

Секция собирается как в текущем приложении (`Options.tsx`: Solution / ToppingUp / Dilution /
Ignore+Accuracy — каждый в своём `Card`): карточка «Опции» + **три отдельные карточки**
«Долив раствора», «Разбавление концентрата», «Расширенные» (по скриншоту заказчика).

1. Карточка «Опции» (без изменений): кнопка «Рассчитать» — стандартный визуал `.btn` (§5),
   `w-full` (рамка/подложка/радиус как у иконных кнопок, без фиолетовой заливки);
   (В приложении подпись английская «Calculate» — по решению заказчика макет весь русский.)
   и блок «Раствор»: сетка `grid grid-cols-2 gap-3` — label над инпутом, поле
   «Объем, л» (демо `1`); подпись секции
   «Концентрация»; ряд `1:` крупно (~2rem) + инпут (демо `1000`, `aria-label="Коэффициент разведения"`);
   ряд «Или [10] мл на [1000] мл рабочего раствора» (два инпута,
   `aria-label="Миллилитры концентрата"`, `aria-label="Миллилитры рабочего раствора"`).
2. Карточка «Долив раствора» — **своя карточка**: чекбокс = аккордеон (демо — **отмечен**);
   при снятии чекбокса JS скрывает блок полей (класс `hidden` → `display:none`), при установке —
   показывает. Поля — строки **подпись СЛЕВА, инпут СПРАВА**
   (`flex items-center gap-2 justify-between`; подпись `flex-1 min-w-0`; инпут фиксированной
   ширины ~`w-24`/`w-28`, текст выровнен справа `text-right`):
   «Новый объем, л» = `10` · «Текущий объем, л» = `5` · «Текущий EC, мСм/см» = **`1,8`** ·
   «EC профиля раствора, мСм/см» = **`1,8`** · «Концентрация солей профиля раствора, г/л» =
   **`194,7`**. Десятичный разделитель — **запятая** (как в приложении/скриншоте; поля со
   знаковыми значениями — `type="text" inputmode="decimal"`); метки **русские** (латинская
   опечатка «Concentration» в подписи солей профиля исправлена).
3. Карточка «Разбавление концентрата» — **своя карточка**: чекбокс = аккордеон (демо —
   отмечен, тот же JS-аккордеон). Поля строками подпись-слева/инпут-справа:
   «Объем, л» = `1`; «Концентрация» — подпись слева, справа `1:` + инпут = `1000`
   (`aria-label="Коэффициент разведения"`); ниже inline-ряд в одну строку:
   «Или [10] мл на [1000] мл.рабочего раствора» — RU-текст дословно (как в приложении),
   маленькие инпуты (~`w-16`) в ряду, `aria-label="Миллилитры концентрата"`,
   `aria-label="Миллилитры рабочего раствора"`.
4. Карточка «Расширенные» — **своя карточка** с `<details>`-аккордеоном (summary «Расширенные»):
   внутри «Игнорировать» — чекбоксы «Кальций», «Магний», «Сера», «Хлор» (все сняты) и

## 5. Тема, цветовые схемы и палитра

**Две ортогональные оси: тема × схема.** Тема — `html[data-theme]` (режимы Система /
Светлая / Тёмная, ключ `theme`); схема — `html[data-scheme]` (5 схем, ключ `scheme`).
Атрибуты ставятся независимо и не влияют друг на друга: любая схема работает в любой теме.

**Три режима темы**: Система / Светлая / Тёмная.

**Механизм (выбранное решение):** одна icon-кнопка с **тремя inline-SVG** в сайдбаре (как текущий
`ColorModeToggle`): sun, moon и «Система» — redraw вместо monitor (т. заказчика):
circle r=8 со stroke + **левая половина залита** (`<path d="M12 4 A8 8 0 0 0 12 20 Z"
fill="currentColor">`), сетка 24×24.
Циклическое переключение **Светлая → Тёмная → Система → …**. Иконка отражает **выбранный
режим**, а не результирующую тему: `light` → sun, `dark` → moon, `system` → полукруг;
всегда виден ровно один svg (JS `applyTheme()` переключает `style.display` по режиму —
SVG-элементы не скрываются свойством `hidden`).
`aria-label="Переключить тему"`, `aria-pressed` = применённая тёмная тема (в режиме «Система»
может быть dark или light — aria-pressed отражает результат).
Режим хранится в `localStorage` (ключ `theme`: `light|dark|system`, дефолт `system`).
JS для «Система» сам решает через `matchMedia("(prefers-color-scheme: dark)")` и пишет
результирующую тему в `data-theme="light|dark"` на `<html>`; слушает изменение media-запроса.
CSS-фолбэк `prefers-color-scheme` до запуска JS — блок `color-default.css`
(перенесён дословно из `style.css`, тот же guard `:root:not([data-theme="light"])`).

**Цветовая схема — dropdown СПРАВА от кнопки темы** (низ сайдбара, тот же ряд
`flex items-center gap-2`): `<select id="scheme-select" aria-label="Цветовая схема">` —
компактный (классы `.input w-40 py-1 px-2 text-xs`, `select.input { appearance: auto }` —
native dropdown), работает в обеих темах. Опции: «По умолчанию» `default`, «Windows 95»
`win95`, «Сайт из 90-х» `retro`, «Природа» `nature`, «Химия и наука» `science`.
Схема хранится в `localStorage` (ключ `scheme`, дефолт `default`). Head-скрипт (DOM-free,
только `documentElement`) до отрисовки ставит **оба** атрибута: `data-theme` и `data-scheme`
(схема из localStorage, иначе `default`). Body-end скрипт: обработчик `change` select —
`html.dataset.scheme` + persist; после reload `applyScheme()` синхронизирует значение select
сохранённой схемой. Логика темы не меняется — оси ортогональны.

**Файлы схем** — `<link>` всех пяти после `style.css`:
`color-default.css` (токены прежнего `style.css` дословно: `:root` светлая,
`:root[data-theme="dark"]` тёмная + media-фолбэк — визуал не меняется),
`color-win95.css`, `color-retro.css`, `color-nature.css`, `color-science.css` —
токены светлого варианта `html[data-scheme="x"]` и тёмного
`html[data-scheme="x"][data-theme="dark"]` (`--bg --card --text --muted --border
--primary --danger --ok --deficit --excess` + все 9 `--el-*`) + scheme-specific
component override'ы (кнопки/карточки/рамки/тени/radius/чипы). Явный scheme-dark блок
(специфичность 0-2-1) перебивает default media-фолбэк (0-2-0).

4. **JavaScript** — только инлайновый `<script>`, минимальный: переключатель темы (~15 строк),
   **селектор цветовой схемы (~10 строк: head-скрипт ставит `data-scheme` из localStorage
   DOM-free; body-end `change` select ⇒ `html[data-scheme]` + persist + sync значения select)**,
   открытие/закрытие drawer (~10 строк), generic открытие/закрытие модалок по
   `data-modal`/`data-modal-close` + `Esc` (~10 строк), плюс `change` чекбокса ряда
   удобрения — переключает `.is-inactive` своего ряда (§3.1) и `change` чекбокса-аккордеона
   карточек «Долив раствора» / «Разбавление концентрата» — скрывает/показывает блок полей
   через класс `hidden` (§3.4, несколько строк).
   Без обработчиков форм, без fetch, без бандлов.
5. **Язык интерфейса** — русский, все строки разметки русские (кнопка — «Рассчитать»).
6. **Иконки** — inline SVG 24×24, скопированы из `packages/icons/src/icons/` этого репозитория
   (набор есть: `menu`, `close`, `save`, `tune`, `broom`, `sun`, `moon`, `plus`, `import`,
   `export`, `restart`, `chevron-down`); иконка режима «Система» (§5) — свой redraw по той
   же сетке 24×24: circle со stroke + залитая левая половина; trash-bin для удаления ряда
   (§3.1) — рисованная inline-иконка в том же stroke-стиле (stroke-width одинаковый у всех
   inline-икон страницы); если файл недоступен — допустимы простые substitute-глифы той же
   сетки 24×24. Цвет — `currentColor`.
7. **Доступность**: `<label>` (явный `for`) для всех полей; `aria-label` на всех иконках-кнопках;
   drawer — `role="dialog" aria-modal="true"`; тема — `aria-pressed`; видимый focus на полях
   (существующий `.input:focus`); семантические `nav/main/section/footer`.
8. **Статика**: расчёты не выполняются; все числа — литералы из §6; dropdownы меняют только
   подпись, ничего не пересчитывают.
